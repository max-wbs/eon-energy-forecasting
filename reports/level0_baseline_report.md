## 2. Evaluation protocol and metrics

Split owned by stage 3 (cutoff 2023-06-30). Train 65,502 rows / 146 households; test 15,583 rows / 70 households.

All models are scored on the 15,505 test rows (99.5%) where every naive forecast is defined, so the comparison is like for like. Metrics: MAE (primary), RMSE, MASE (fleet median scale 4.708 kWh; 679 rows on the fallback). R2 is not reported.

## 3. Hyperparameter selection

`min_samples_leaf` swept over [1, 5, 20, 50] on a time-based validation slice (train dates after 2022-10-27, 13,806 rows); validation MAE 5.174, 5.138, 5.150, 5.224 kWh.

Settings within one standard error of the best: [1, 5, 20] (SE 0.0436 kWh). The one-standard-error rule selects the most constrained of these, hence **min_samples_leaf = 20**.
